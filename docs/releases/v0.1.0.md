# toyoterm 0.1.0

The first experimental release of toyoterm, a programmable terminal emulator
built with Rust and embedded mruby.

## Highlights

- Native PTY sessions, tabs, workspaces, split panes, search, selection, and GPU rendering.
- Ruby configuration, key bindings, callbacks, commands, themes, and live reload.
- Shell integration and bounded support for Sixel, Kitty graphics, and iTerm2 inline images.
- Native packages for Linux x86_64/aarch64, macOS x86_64/aarch64, and Windows x86_64.

## Getting started

Download the package for your OS and verify its checksum against `SHA256SUMS`.
The package includes English and Japanese READMEs, installation instructions,
the API reference, and `examples/default_config.rb`. toyoterm has no built-in
GUI key bindings; copy the bindings you want into your configuration file.

## Current limits

toyoterm is an experimental project. It runs in one OS window and does not
persist sessions between launches. Configuration and required Ruby libraries
run as trusted code. Linux packages depend on baseline system libraries. The
macOS app is unsigned and not notarized, and the Windows binaries are unsigned;
see the included installation guide for platform-specific steps.

# toyoterm 0.1.0（日本語）

Rustと組み込みmrubyで作られた、プログラム可能な実験的ターミナルエミュレータの初回リリースです。

## 主な機能

- ネイティブPTY、タブ、Workspace、Pane分割、検索・選択、GPU描画。
- Rubyによる設定、キーバインド、コールバック、コマンド、テーマ、設定の再読込。
- シェル連携と、サイズ制限付きのSixel・Kitty graphics・iTerm2画像表示。
- Linux x86_64/aarch64、macOS x86_64/aarch64、Windows x86_64向けパッケージ。

## 使い始めるには

お使いのOS向けパッケージをダウンロードし、`SHA256SUMS`でチェックサムを確認してください。
パッケージには英語・日本語のREADME、インストール手順、APIリファレンス、
`examples/default_config.rb`が含まれます。GUIキーバインドは組み込まれていないため、
必要な設定を設定ファイルにコピーしてください。

## 現在の制限

toyotermは実験的なプロジェクトです。OSウィンドウは1つで、セッションの永続化には
対応していません。設定とrequireしたRubyライブラリは信頼済みコードとして動作します。
Linux版は基本的なシステムライブラリに動的リンクします。macOSアプリは署名・公証されておらず、
Windowsの実行ファイルも署名されていません。各OSでの導入手順は同梱のガイドを参照してください。
